# LUXORA — Luxury Watch Landing Page

A modern and elegant luxury watch landing page built with HTML, CSS, Bootstrap, and JavaScript.

## 🌐 Live Demo

[View Live Demo](https://youssef-ibrahim200038542.github.io/luxora-watch-landing-page/)

## ✨ Features

- Fully responsive design
- Modern and elegant luxury watch interface
- Responsive navigation bar
- Hero section with call-to-action
- Watch collection with product cards
- Interactive watch details modal
- Dynamic product information
- Why LUXORA section
- About section
- Customer reviews section
- Responsive footer
- Smooth scrolling and interactive UI elements

## 💡 Project Highlights

LUXORA is a luxury watch landing page designed with a clean, modern, and premium visual style.

The project focuses on responsive design and interactive user experience. JavaScript is used to create a dynamic product details modal, allowing users to view watch information without leaving the main page.
